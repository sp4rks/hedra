# Hedra

Hedra lets consuming applications define their data and expose it through collections.

## Language

**Model**:
The definition of the shape and validity of an application's records.

**Collection**:
A named set of records governed by one model.

**Record**:
An individual item in a collection that conforms to its model.

**Consuming application**:
An application built with Hedra that defines its own models and collections.
